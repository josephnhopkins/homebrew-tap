# Nextwaveweb's Homebrew tap

Homebrew casks for Nextwaveweb Ltd's Webrender desktop apps on macOS (Apple silicon, macOS 14 Sonoma or newer).

    brew install --cask josephnhopkins/tap/webrender-markdown-editor

| Cask | App | Page |
|---|---|---|
| `webrender-markdown-editor` | Webrender Markdown Editor | https://nextwaveweb.co.uk/products/webrender-markdown-editor |

Each cask installs the notarized disk image from the app's GitHub Release. This repository holds no source code.
